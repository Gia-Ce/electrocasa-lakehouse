# ElectroCasa Lakehouse

Esqueleto inicial del repositorio para el proyecto integrador de ElectroCasa.

```text
electrocasa-lakehouse/
├── databricks.yml
├── resources/
│   ├── electrocasa_pipeline.yml
│   └── electrocasa_job.yml
├── src/
│   └── electrocasa/
│       ├── transformations/
│       └── utils/
├── notebooks/
│   └── 00_setup.ipynb
└── README.md
```

La implementacion de las transformaciones, recursos Databricks, aprovisionamiento y documentacion del proyecto se agregara sobre esta estructura.
